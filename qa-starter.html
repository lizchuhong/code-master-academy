1. Mở terminal và chạy lệnh đầu tiên

Terminal là cửa sổ để gõ lệnh. Thư mục hiện tại là nơi lệnh đọc hoặc tạo tệp. Trên Windows, mở Windows Terminal rồi chọn PowerShell. Nếu dùng Command Prompt, thay Get-Location bằng cd.

  1. Cài Node.js bản LTS từ trang chính thức. Mở lại terminal và gõ node -v. Nếu thấy số phiên bản, máy đã tìm được Node.
  2. Gõ npm.cmd -v trong PowerShell để kiểm tra npm. npm cài thư viện cho dự án.
  3. Gõ lần lượt từng dòng dưới đây. Nếu đã có thư mục cùng tên, dùng tên khác.
mkdir qa-tu-0
cd qa-tu-0
Get-Location
node -e "console.log(2 + 3)"

7. Chuyển một test case tay thành Playwright

Mở lab và làm tay trước. Dùng tài khoản mẫu qa-demo với mật khẩu test-only-01. Đăng nhập đúng phải thấy tiêu đề “Số dư tài khoản”. Đăng nhập sai phải có lỗi. Thử 9999 rồi 10000 VND để xem hai phía của hạn mức tối thiểu.

Mở Mini Banking Lab Tải qa-practice.html Tải qa-playwright.spec.js

Lưu hai tệp vào qa-tu-0. Nếu Windows ẩn đuôi tệp, kiểm tra tên cuối cùng là .html và .js. Trong PowerShell đang ở đúng thư mục, chạy lần lượt. Bỏ qua dòng init nếu đã chạy ở phần Newman.

npm.cmd init -y
npm.cmd install -D @playwright/test
npx.cmd playwright install chromium
npx.cmd playwright test qa-playwright.spec.js --reporter=list

Trong tệp test, test(...) đặt tên cho ca thử. page.getByLabel(...) chọn trường theo nhãn. await ...fill(...) nhập và chờ thao tác. await expect(...).toBeVisible() là phép so expected với UI. beforeEach mở lại lab để mỗi ca bắt đầu từ trạng thái sạch.

Đọc một ca test từng dòng 
test('đăng nhập đúng', async ({ page }) => {
  await page.getByLabel('Tên đăng nhập').fill('qa-demo');
  await page.getByLabel('Mật khẩu').fill('test-only-01');
  await page.getByRole('button', { name: 'Đăng nhập' }).click();
  await expect(page.getByRole('heading', { name: 'Số dư tài khoản' })).toBeVisible();
});

async ({ page }) => { ... } là hàm của ca test. Playwright cung cấp page cho hàm. Bốn dòng bên trong tương ứng với ba thao tác và một bước kiểm tra. Trong tệp đầy đủ, require('@playwright/test') lấy các hàm từ thư viện vừa cài.

Qua bước này khi chạy được ba ca mẫu, đổi một expected để test đỏ, đọc dòng lỗi, rồi khôi phục để xanh. Sau đó tự thêm case 200001 VND bị chặn và giải thích expected trước khi chạy.

Gom các thao tác lặp vào Page Object

Khi hai test dùng cùng form, đưa ba bước điền tên, điền mật khẩu và bấm nút vào một method. class mô tả đối tượng, new LoginPage(page) tạo một đối tượng cho ca test và this.page giữ trang do Playwright cấp.

Thử trên tệp Playwright đã tải

Dán class này vào qa-playwright.spec.js trước test.beforeEach.

class LoginPage {
  constructor(page) {
    this.page = page;
  }

  async signIn(username, password) {
    await this.page.getByLabel('Tên đăng nhập').fill(username);
    await this.page.getByLabel('Mật khẩu').fill(password);
    await this.page.getByRole('button', { name: 'Đăng nhập' }).click();
  }
}

Tệp mẫu gọi hàm login(page) để gộp ba thao tác. Trong ca đăng nhập đúng, thay dòng gọi hàm bằng hai dòng dưới và giữ nguyên assertion.

const loginPage = new LoginPage(page);
await loginPage.signIn('qa-demo', 'test-only-01');

Làm tương tự trong ca sai mật khẩu, giữ wrong-test-password. Đổi cả lệnh đăng nhập của ca chuyển tiền. Khi ba ca đều dùng Page Object, có thể xóa hàm login cũ.

Qua phần này khi các ca test vẫn xanh và bạn chỉ được chỗ sửa khi nhãn “Đăng nhập” thay đổi. Quay lại bài Page Object

8. Git, CI và đọc lỗi

Cài Git và kiểm git --version. Git lưu lịch sử dự án. GitHub lưu repository từ xa. Khi đã chạy test trên máy, tạo .gitignore chứa node_modules/, test-results/ và playwright-report/ trên ba dòng. Giữ package.json và package-lock.json để CI cài lại đúng thư viện.

git init
git status
git add .
git diff --cached --stat
git commit -m "Add first QA automation tests"

Nếu Git hỏi tên hoặc email, đặt git config --local user.name và git config --local user.email với giá trị của bạn, rồi chạy lại lệnh commit. Tạo một repository trống của bạn trên GitHub. Thay URL mẫu ở dòng thứ hai bằng URL clone của repo đó, rồi chạy.

git branch -M main
git remote add origin https://github.com/your-name/qa-tu-0.git
git push -u origin main

Tạo tệp .github/workflows/qa.yml theo mẫu dưới đây, commit và push lần nữa. Mở tab Actions trên GitHub để xem lần chạy.

Xem mẫu GitHub Actions 
name: QA smoke
on: [push]
permissions:
  contents: read
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - uses: actions/setup-node@v6
        with:
          node-version: '24'
          cache: npm
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - run: npx playwright test qa-playwright.spec.js --reporter=list

Qua bước này khi bạn chỉ được bước lỗi trong log, phân biệt lỗi thiếu thư viện với assertion fail và tự chạy lại trên máy. Repo thực hành chỉ dùng dữ liệu giả.
